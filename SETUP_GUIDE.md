# Quick Setup Guide - Business Unit Architecture\n\n## Prerequisites\n- Laravel 11+ with Pest testing framework\n- Node.js and npm for frontend\n- Database (MySQL/SQLite)\n\n## Installation & Setup\n\n### 1. Backend Setup\n\n```bash\n# Install dependencies\ncomposer install\n\n# Setup environment\ncp .env.example .env\nphp artisan key:generate\n\n# Run migrations\nphp artisan migrate\n\n# Seed sample data (optional)\nphp artisan db:seed\n```\n\n### 2. Frontend Setup\n\n```bash\n# Install npm dependencies\nnpm install\n\n# Build assets\nnpm run build\n\n# For development\nnpm run dev\n```\n\n### 3. Business Unit Configuration\n\n#### Create Sample Companies\n\n```php\n// In database seeder or tinker\nCompany::create([\n    'company_code' => 'VIS001',\n    'name' => 'VISMASS Operations',\n    'vat_number' => 'VAT123456789'\n]);\n\nCompany::create([\n    'company_code' => 'MAL001', \n    'name' => 'MALIBO Operations'\n]);\n```\n\n#### Create Sections\n\n```php\n// Main stock section for VISMASS\nSection::create([\n    'company_code' => 'VIS001',\n    'section_code' => 'MAIN001',\n    'name' => 'Main Warehouse',\n    'is_main_stock' => true\n]);\n\n// Printing section for MALIBO  \nSection::create([\n    'company_code' => 'MAL001',\n    'section_code' => 'PRINT001', \n    'name' => 'Printing Department',\n    'is_main_stock' => false,\n    'section_type' => 'store'\n]);\n```\n\n#### Create Test Users\n\n```php\n// VISMASS user\nUser::create([\n    'name' => 'VISMASS Manager',\n    'email' => 'vismass@example.com',\n    'password' => Hash::make('password'),\n    'company_code' => 'VIS001'\n]);\n\n// MALIBO user\nUser::create([\n    'name' => 'MALIBO Manager', \n    'email' => 'malibo@example.com',\n    'password' => Hash::make('password'),\n    'company_code' => 'MAL001'\n]);\n```\n\n## Testing the Setup\n\n### 1. Run Tests\n\n```bash\n# Run all tests\nphp artisan test\n\n# Run specific business unit tests\nphp artisan test --filter BusinessUnitMiddleware\nphp artisan test --filter VismassBusinessLogic\nphp artisan test --filter MaliboBusinessLogic\n```\n\n### 2. Test API Endpoints\n\n#### VISMASS Endpoints\n```bash\n# Login as VISMASS user\ncurl -X POST http://localhost/login \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"email\":\"vismass@example.com\",\"password\":\"password\"}'\n\n# Access VISMASS routes\ncurl -X GET http://localhost/vismass/stock \\\n  -H \"Authorization: Bearer {token}\"\n```\n\n#### MALIBO Endpoints\n```bash\n# Login as MALIBO user  \ncurl -X POST http://localhost/login \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"email\":\"malibo@example.com\",\"password\":\"password\"}'\n\n# Access MALIBO routes\ncurl -X GET http://localhost/malibo/deliveries \\\n  -H \"Authorization: Bearer {token}\"\n```\n\n### 3. Frontend Testing\n\n1. Navigate to the application in browser\n2. Login with test credentials\n3. Verify business unit-specific menus appear\n4. Test batch management components\n5. Verify access restrictions work correctly\n\n## Development Workflow\n\n### Adding New Features\n\n1. **Identify Business Unit**: Determine if feature belongs to VISMASS, MALIBO, or shared\n\n2. **Create Routes**: Add to appropriate route file\n   ```php\n   // For VISMASS feature\n   // File: routes/vismass.php\n   Route::get('/new-feature', [NewController::class, 'index'])->name('new-feature.index');\n   ```\n\n3. **Create Controller**: Add business unit context\n   ```php\n   class NewController extends Controller \n   {\n       public function index(Request $request)\n       {\n           $businessUnit = $request->get('business_unit'); // From middleware\n           // Feature logic here\n       }\n   }\n   ```\n\n4. **Add Tests**: Create corresponding test files\n   ```php\n   test('new feature works for vismass', function () {\n       // Test implementation\n   });\n   ```\n\n5. **Frontend Components**: Create in appropriate folder\n   ```\n   resources/js/components/vismass/NewFeature.tsx\n   resources/js/components/malibo/NewFeature.tsx\n   ```\n\n### Database Changes\n\nWhen adding tables that need business unit separation:\n\n```php\nSchema::create('new_table', function (Blueprint $table) {\n    $table->id();\n    $table->string('company_code')->index();\n    $table->string('section_code')->nullable()->index();\n    // Add foreign key constraints\n    $table->foreign('company_code')->references('company_code')->on('companies');\n    $table->timestamps();\n});\n```\n\n## Debugging\n\n### Common Issues\n\n1. **Access Denied**: Check user company code and section assignments\n2. **Route Not Found**: Verify route registration in bootstrap/app.php\n3. **Middleware Not Working**: Clear cache and check middleware registration\n\n### Debug Commands\n\n```bash\n# Clear all caches\nphp artisan optimize:clear\n\n# Check routes\nphp artisan route:list --name=vismass\nphp artisan route:list --name=malibo\n\n# Check middleware\nphp artisan route:list --middleware=business.unit\n```\n\n## Production Deployment\n\n### Environment Variables\n\nEnsure these are set in production `.env`:\n\n```env\nAPP_NAME=\"Distribution System\"\nAPP_ENV=production\nAPP_DEBUG=false\nAPP_URL=https://yourdomain.com\n\n# Database configuration\nDB_CONNECTION=mysql\nDB_HOST=127.0.0.1\nDB_PORT=3306\nDB_DATABASE=distribution_system\nDB_USERNAME=username\nDB_PASSWORD=password\n\n# Business Unit Configuration\nVISMASS_COMPANY_PREFIX=VIS\nMALIBO_COMPANY_PREFIX=MAL\n```\n\n### Deployment Steps\n\n```bash\n# Build production assets\nnpm run build\n\n# Optimize Laravel\nphp artisan config:cache\nphp artisan route:cache\nphp artisan view:cache\n\n# Run migrations\nphp artisan migrate --force\n\n# Set permissions\nchown -R www-data:www-data storage bootstrap/cache\nchmod -R 775 storage bootstrap/cache\n```\n\n## Support\n\nFor issues or questions:\n1. Check the logs: `storage/logs/laravel.log`\n2. Run tests to identify problems\n3. Review the Business Unit Architecture documentation\n4. Check middleware and route configurations
